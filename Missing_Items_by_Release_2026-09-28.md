# Missing Genshin Tracker entries by introduction version

Reviewed 28 September 2026 (Sydney date). Compared the local corrected SQLite database (104 characters, 219 weapons, 453 materials) with genshin-db English data and its version import logs. The database was not changed. The logged version is the first data import, not necessarily the date an item became obtainable. For banners, “first” and “second” refer to the initial event-wish phase, not reruns.

The 6.0 weapon names may correspond to the nine existing unnamed/placeholder weapon rows, so match their IDs and costs before adding anything. The three `Snezhnaya 1` placeholder material tiers in the committed database are not in this 453-row local database. The audit also showed historical PlayStation and quest weapons, which are listed separately. Entries for 7.0 and 7.1 are pending verification against live release notices.
