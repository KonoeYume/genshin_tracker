Inventory display update
========================

Replace app_v2.py in your project folder with this version. If your server
is running with --reload, refresh http://127.0.0.1:8000/ after replacing it.

Required, Owned and Still needed are plain-text columns. Enter a new owned
total in the separate Update value box and click Save. The box starts empty
and clears when the page refreshes after a successful save. Saving 0 is valid.
Other calculations and database tables are unchanged.
