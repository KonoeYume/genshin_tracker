Goal layout update
==================

Replace app_v2.py in your project folder with this version and refresh
http://127.0.0.1:8000/ (restart uvicorn if it is not using --reload).

Character Goal and Weapon Goal show Current Level and Target Level on
separate rows, then Current Ascension and Target Ascension on separate
rows. Each of the three character talents has separate current and target
rows. The weapon selection still distinguishes individual owned copies.

Inventory editing and all database calculations are unchanged.
